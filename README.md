# 月光奇植园 · Moonlit Garden

一款中文像素风花园增量游戏。购买种子、点击浇水、收获金币、雇用蜗牛，最终培育永恒星之花。通关后继续自由种植。

[在线游玩](https://xcymm3.github.io/Coin/)

## 本地运行

需要 Node.js 22.18+ 和 pnpm 11。

```sh
pnpm install --frozen-lockfile
pnpm dev --host 127.0.0.1
```

打开开发服务输出的地址，默认是 http://127.0.0.1:5173/ 。

## 内容

- 十种植物：三种免费低级植物、三种中级植物、三种高级植物、一种终极植物。
- 六种中高级效果：水滴花自身吸水加成、自然生长光环、被动产币、收获群体加速、点击光环、蜗牛光环。
- 十二种升级，分为照料、花园、助手三类。初始六个花盆，最多十五个。
- 按等级购买随机种子：低级免费、中级 50、高级 300 金币（堆肥可折扣），本级三种各 1/3 概率。终极种子固定。
- 手动水壶需要移动、倾倒和到水池装填，每次只浇一株；初始容量 4 滴，升级后最多 10 滴。
- 助手完整流程：蜗牛取水再浇水；松鼠回种子箱补货再播种；甲虫采摘装篮、运回收获站后结算金币。背篓和种子袋可扩容，可分别暂停收获和播种。
- 可见升级：水壶、背篓、容量格、蜗牛跑鞋和花园灯笼。原「雨露共享」升级迁移为水壶容量。
- 观赏模式隐藏商店、数值提示和通关弹窗，关闭操作音效并保留 BGM、植物成长及助手工作；按 Esc 或右上角按钮退出。
- 设置中提供重置按钮，确认后重新开始，保留音效偏好。
- 开始菜单、游戏设置、植物图鉴、玩法指南、通关界面。
- 合成音效、音量设置、动画开关、系统减少动态效果支持。
- 每三秒本地存档；最多三十分钟离线成长；菜单暂停。
- 手机面板切换、键盘操作、原生对话框焦点约束。

## 通关节奏

累计收益达到 120 / 1,800 金币解锁中级 / 高级种子。培育成熟全部三种高级植物后，可以花费 6,500 金币购买永恒星之花。

星之花基础生长 480 秒，手动浇水每次增加 0.5 秒、蜗牛每次增加 0.25 秒；不接受普通植物的其他加速。成熟即通关，不需要收获触发。它不会被自动收获或自动播种。

当前搬运与装水版本以五组固定随机序列、约每 3 秒一次操作（空壶时改为装水）的策略模拟，通关用时 **12:01.5–14:02.5**。这属于数值模拟，本次浏览器验证覆盖工作流、装水、观赏模式和重置，未重新进行整局真人计时试玩。

历史记录：初版（指定品种、批量自动化）的真实浏览器试玩在 **14:33** 通关。随机种子与逐盆动物作业版另外进行了五组固定随机序列的策略模拟：约每 3 秒点击一次，通关用时 **12:29–13:17**；这不是新版完整真人试玩记录。不同的随机结果、点击频率和升级顺序会改变实际用时。详细记录见 [试玩与验证](docs/PLAYTEST.md)。

## 验证

```sh
pnpm test
pnpm lint
pnpm build
```

游戏计算在 `src/game.ts`，界面在 `src/Garden.tsx`，音效在 `src/audio.ts`，风格在 `src/garden.css`、`src/garden-scene.css` 与 `tokens.css`。动物任务状态和随机序列随存档保存，旧存档自动迁移。

## 部署

推送到 `main` 后，现有 GitHub Actions 工作流自动构建并部署到 GitHub Pages。`PAGES_BASE_PATH=/Coin/` 控制生产资源路径，也支持手动触发工作流。
