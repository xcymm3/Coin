# 最后一枚 · THE LAST COIN

React + TypeScript + Canvas 制作的末日地堡投币增量游戏 Demo，使用 pnpm 和 Vite。

## 本地运行

需要 Node.js 22.12+（推荐 Node.js 22 LTS）及 pnpm。

```sh
pnpm install
pnpm dev
```

打开终端显示的本地地址，点击「启动工作台」。

```sh
pnpm build       # 类型检查并构建到 dist/
pnpm preview     # 预览生产构建
pnpm test        # 游戏规则测试
pnpm exec playwright install chromium
pnpm test:e2e    # 浏览器交互与响应式检查
```

## 操作与规则

- 鼠标移动瞄准，左右移动轻微转头，左键点击发射铜币。触屏可直接点按场景。
- 键盘 1 / 2 / 3 选择熔炉 / 发条 / 分流器，再按空格发射；P 或 Esc 暂停。
- **铸币熔炉**：初始需要 1000 点命中进度。升级使设备命中效率翻倍，下一次需求翻倍。
- **机械分流器**：按 10 点双发 → 50 点三发 → 150 点自动供币 → 300、600……点自动供币加速的顺序刷新。
- **应急发条**：初始 100 秒，每秒减 1；每枚命中加 1 秒，可超过 100 秒，归零立即失败。升级弹体不会改变续命量。
- 铜币按实际落点和到达时间结算，多发分别结算。飞行途中倒计时归零仍会失败。
- 自动供币解锁后，可在设备栏选择自动射击目标；发射间隔最低 0.2 秒。
- 切换到后台、打开手册会暂停。关闭手册恢复打开前的运行状态。失败记录保存在本地浏览器中；刷新页面会重开本局。

## 实现

- `src/game.ts`：独立游戏规则及状态转换。
- `src/scene.ts`：960 × 620 Canvas 场景，分层视差、铜币轨迹、命中检测、机械动画、粒子和发射循环。
- `src/audio.ts`：Web Audio 合成射击、命中、升级及警报音。
- `src/App.tsx`：React 状态界面、键盘控制、暂停、说明和失败重开。
- `tokens.css`：可调整的界面颜色及字体变量。

全部场景美术由代码绘制，无外部图片或音频服务依赖。像素风为原创军工地堡视觉，没有使用《魂斗罗》的素材。该 Demo 使用有限视角的伪 3D 绘制，不包含真实物理引擎、离线收益或完整的关卡系统。
