# 月光奇植园 · Moonlit Garden

一款中文像素风花园增量游戏。购买种子、点击浇水、收获金币、雇用蜗牛，最终培育永恒星之花。通关后继续自由种植。

[在线游玩](https://xcymm3.github.io/Coin/)

## 本地运行

需要 Node.js 22.18+ 和 pnpm 11。

```sh
pnpm install --frozen-lockfile
pnpm dev --host 127.0.0.1
```

打开开发服务输出的地址，默认是 http://127.0.0.1:5173/ 。

## 内容

- 29 种植物，五秒萌发后显示各自独特的像素幼芽与配色。
- 八档种子：普通、稀有、珍贵、超凡、神话、远古、星界、终极；前七档各四种植物，终极仅永恒星之花。
- 所有植物仅有成长时间和收获价值，没有被动产币、光环或收获附带效果；永恒星之花保留成熟通关。
- 商店分为升级、雇佣、装饰，只显示待购项。每园三项专属研究，全园共享，合计十五项。每园初始四个花盆，每次付费扩建增加一盆，五座花园各最多十五盆，共 75 盆。通过花园场景左右边缘的箭头切换，园名位于场景顶部，扩建入口位于商店；精简顶部布局以扩大花园主画面。
- 普通种子免费，其余价格依次为 50、500、10,000、500,000、50,000,000、10,000,000,000、15,000,000,000,000 金币。所有非终极种子都能抽出二十八种植物，种子栏仅显示购买信息；终极固定。完整概率与收益见 [经济设计](docs/ECONOMY.md)。
- 顶部木框方格工具栏：彩色水壶、肥料袋、小推车与铲子，水壶通过满水、半满、将空、空壶四档外观表示余量，不显示数值。点击花园左下角水池补水；工具栏、倾倒动画与打水动画使用同一水壶外观。选择水壶后点击单株植物，只在目标旁播放倾倒动画，水壶不作为场景角色移动。内部容量初始 4 次、升级后最多 128 次。每株独立冷却 1.2 秒，动画期间不能重复浇同一株，但可立即浇其他植物；点击时扣水，动画结束结算成长。
- 小推车：先选植物，再点空盆移动或另一株交换，保留成长进度；再次点击原盆取消。默认点击空盆播种、点击成熟植物收获（水壶选中时同样适用）；铲子可挖掉任意阶段植物，不给收益或收获效果。再次点击已选工具取消选择。肥料仅在手动收获时以 5% 概率掉落，甲虫自动收获不掉落，选中后消耗一份让未成熟的非终极植物立即成熟。
- 助手完整流程：蜗牛取水再浇水；松鼠回种子箱补货再播种；甲虫采摘装篮、运回收获站后结算金币。背篓和种子袋可扩容，可分别暂停收获和播种。
- 每园独立雇佣蜗牛、甲虫、松鼠，每种最多五只。装备依次为木、铜、铁、金、钻石，动物身上不显示装备或携带物；强化仅作用本园同种动物。新园没有动物和装饰。
- 观赏模式隐藏商店、数值提示和通关弹窗，关闭操作音效并保留 BGM、植物成长及助手工作；按 Esc 或右上角按钮退出。
- 设置中提供重置按钮，确认后重新开始，保留音效偏好。
- 开始菜单、游戏设置、收获图鉴、玩法指南、通关界面。图鉴未收获品种显示剪影，隐藏名字和资料；实际手动收获或甲虫采摘后解锁，并累计该品种收获次数。成熟和铲除不计数。旧存档未记录品种次数，保留旧总收获量，品种统计从更新后开始。
- 合成音效、音量设置、动画开关、系统减少动态效果支持。
- 每三秒本地存档；最多三十分钟离线成长；菜单暂停。
- 手机面板切换、键盘操作、原生对话框焦点约束。

## 收集与花园氛围

- 仅七个常规品阶中最稀有的品种可出现一个专属变种，各有不同造型，条件概率 10%，收获收益 ×2。终极无变种；其余品种不变异。
- 外观变体培育成熟即永久记录到图鉴；原有品种仍以实际收获解锁，收获次数单独统计。
- 每园六项纯外观装饰，首园价格从 250 到 100 亿；后四园分别乘以 8、64、512、4096。购买后从商店移除，在设置中隐藏/展示。
- 每隔 5–10 分钟随机出现细雨、萤火虫之夜或彩虹，持续 15 秒，仅视觉效果。跟随游戏时间暂停、存档和离线结算。
- 细节与价格见 [收集与天气规则](docs/COLLECTIBLES.md)。

## 通关节奏

新档以每两秒一次操作为基准，目标依次为 10 / 10 / 12 / 13 / 15 / 5 分钟。15 局实际 reducer 模拟的阶段平均为 9.87 / 9.92 / 12.07 / 13.80 / 15.28 / 5.06 分钟，合计约 66 分钟。各局随机品种和操作策略会影响用时，范围、模拟策略和前期活动指标见 [当前节奏验收](docs/PACING.md)。

种子仅检查当前余额，终极价格 15 万亿；没有强制等待计时锁。雇佣松鼠后为本园指定普通至星界种子，缺钱等待。终极基础成长 27,000 秒；第五园完成土壤研究后自然成长约 5.6 分钟，配合浇水约 5 分钟，不能施肥，也不会被自动采收。旧存档保留已有盆数、资产及比例成长进度，目标时长以新档为准。

运行 `npm run check:pacing` 复现 15 局验收；`npm test`、`npm run build`、`npm run lint` 运行规则、构建和静态检查。开发预览 `/tests/fixtures/gardens.html` 不写入真实存档。

## 素材与许可

图像素材与字体均随项目本地打包，不依赖第三方运行时接口。素材生成说明、提示词与字体许可见 [ASSETS.md](docs/ASSETS.md)。

### 种子萌发

新播种的植物前 5 秒有效成长只显示统一的神秘种子，隐藏名称、收益和成熟时间；揭晓后显示对应品种幼芽。自然生长、土壤和浇水均推进萌发，灯笼只增加整体初始成长，不跳过揭晓等待。珍贵及以上植物揭晓会播放像素闪光与专属音效，遵循音效设置和观赏模式。铲除不退种子费用。移动和存档保留萌发进度；旧存档植物按已有成长判断是否揭晓。六品阶版本重设价格与成长经济，旧存档按成长比例迁移，保留已有金币与通关记录。
