# 月光奇植园 · Moonlit Garden

一款中文像素风花园增量游戏。购买种子、点击浇水、收获金币、雇用蜗牛，最终培育永恒星之花。通关后继续自由种植。

[在线游玩](https://xcymm3.github.io/Coin/)

## 本地运行

需要 Node.js 22.18+ 和 pnpm 11。

```sh
pnpm install --frozen-lockfile
pnpm dev --host 127.0.0.1
```

打开开发服务输出的地址，默认是 http://127.0.0.1:5173/ 。

## 内容

- 21 种植物，五秒萌发后显示各自独特的像素幼芽与配色。
- 六档种子：普通、稀有、珍贵、超凡、神话、终极；前五档各四种植物，终极仅永恒星之花。
- 所有植物仅有成长时间和收获价值，没有被动产币、光环或收获附带效果；永恒星之花保留成熟通关。
- 十二种升级，分为照料、花园、助手三类。初始十个花盆，最多十五个。
- 普通种子免费，其余价格依次为 50、300、1,800、10,800、64,800 金币。所有非终极种子都能抽出二十种植物，商店展示每株实际概率；终极固定。完整概率与收益见 [经济设计](docs/ECONOMY.md)。
- 顶部工具栏：选择水壶后点击单株植物，只在目标旁播放倾倒动画，水壶不作为场景角色移动。右侧显示充能与「装满」按钮，初始 4 格、升级后最多 10 格。每株独立冷却 1.2 秒，动画期间不能重复浇同一株，但可立即浇其他植物；点击时扣水，动画结束结算成长。
- 小推车：先选植物，再点空盆移动或另一株交换，保留成长进度；再次点击原盆取消。默认点击空盆播种、点击成熟植物收获（水壶选中时同样适用）；铲子可挖掉任意阶段植物，不给收益或收获效果。再次点击已选工具取消选择。肥料暂未开放。
- 助手完整流程：蜗牛取水再浇水；松鼠回种子箱补货再播种；甲虫采摘装篮、运回收获站后结算金币。背篓和种子袋可扩容，可分别暂停收获和播种。
- 可见升级：水壶、背篓、容量格、蜗牛跑鞋和花园灯笼。原「雨露共享」升级迁移为水壶容量。
- 观赏模式隐藏商店、数值提示和通关弹窗，关闭操作音效并保留 BGM、植物成长及助手工作；按 Esc 或右上角按钮退出。
- 设置中提供重置按钮，确认后重新开始，保留音效偏好。
- 开始菜单、游戏设置、植物图鉴、玩法指南、通关界面。
- 合成音效、音量设置、动画开关、系统减少动态效果支持。
- 每三秒本地存档；最多三十分钟离线成长；菜单暂停。
- 手机面板切换、键盘操作、原生对话框焦点约束。

## 通关节奏

以十盆、无升级、不浇水、及时收获补种为基准，五次进阶阶段分别约 **5、20、80、320、1280 分钟**。按累计收获毛收入解锁，合计约 28 小时 25 分钟后解锁终极，再培养星之花。具体数值、21 种植物、概率和模拟结果见 [经济设计](docs/ECONOMY.md)。

星之花基础生长 480 秒，接受与其他植物相同的手动浇水、蜗牛浇水、土壤与萤火灯笼加成。手动浇水基础 +2 秒，每级手套再 +2 秒；蜗牛基础 +3 秒，每级大号水壶再 +3 秒。土壤每级使所有植物自然生长 +15%，萤火灯笼每级为所有植物提供 10% 初始成长。成熟即通关，不需要收获触发。它不会被自动收获或自动播种。

助手按「蜗牛 → 大号水壶 → 跑鞋 → 甲虫 → 松鼠」逐项解锁，升级卡显示未达成条件；更高等级也要求更多时间、收益和收获数量。已购买的助手不会被收回。

| 首次解锁 | 最早花园时光 | 累计收益 | 收获数量 | 购买价格 |
| --- | --- | --- | --- | --- |
| 浇水蜗牛 | 02:00 | 650 | 18 | 400 |
| 大号水壶 | 02:30 | 1,000 | 22 | 350 |
| 蜗牛跑鞋 | 03:00 | 1,600 | 26 | 450 |
| 收获甲虫 | 04:00 | 3,200 | 32 | 1,200 |
| 播种松鼠 | 05:30 | 6,000 | 40 | 2,200 |

100 组模拟阶段平均耗时：**5.08 / 20.23 / 79.66 / 321.16 / 1280.21 分钟**。另有 100 组独立样本和实际游戏 reducer 交叉验证。运行 `node --experimental-strip-types scripts/balance-check.mjs` 可复现。旧版十余分钟试玩属于历史版本，详见 [试玩记录](docs/PLAYTEST.md)。

```sh
pnpm build
```

## 素材与许可

图像素材与字体均随项目本地打包，不依赖第三方运行时接口。素材生成说明、提示词与字体许可见 [ASSETS.md](docs/ASSETS.md)。

### 种子萌发

新播种的植物前 5 秒有效成长只显示统一的神秘种子，隐藏名称、收益和成熟时间；揭晓后显示对应品种幼芽。自然生长、土壤和浇水均推进萌发，灯笼只增加整体初始成长，不跳过揭晓等待。珍贵及以上植物揭晓会播放像素闪光与专属音效，遵循音效设置和观赏模式。铲除不退种子费用。移动和存档保留萌发进度；旧存档植物按已有成长判断是否揭晓。六品阶版本重设价格与成长经济，旧存档按成长比例迁移，保留已有金币与通关记录。
