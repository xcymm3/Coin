# 最后一枚 · THE LAST COIN

React + TypeScript + Three.js 制作的哥特式末日投币增量游戏，使用 pnpm 和 Vite。玩家手持铸币枪，在真实三维圣堂中守护圣约机，完成十二分钟守夜。

在线试玩：[最后一枚](https://xcymm3.github.io/Coin/)

## 自动部署

代码仓库：[xcymm3/Coin](https://github.com/xcymm3/Coin)。每次推送到 `main`，GitHub Actions 会使用 Node.js 22 和项目指定的 pnpm 版本安装锁定依赖，运行游戏规则测试及类型检查，构建并发布到 GitHub Pages。测试或构建失败时不会发布。

工作流为 `.github/workflows/deploy.yml`，也可在 Actions 页手动运行。Pages 的发布来源使用 **GitHub Actions**，无需维护 `gh-pages` 分支，也无需添加个人令牌。

部署时通过 `PAGES_BASE_PATH` 设置 Pages 子路径，确保 `/Coin/` 下脚本、样式与图标正确加载。本地开发默认仍使用 `/`。

## 本地运行

需要 Node.js 22.12+（推荐 Node.js 22 LTS）及 pnpm。

```sh
pnpm install
pnpm dev
```

打开终端显示的本地地址，点击「握紧铸币枪」，跟随末日生存系统完成游戏内引导；也可以跳过引导。

```sh
pnpm build       # 类型检查并构建到 dist/
pnpm preview     # 预览生产构建
pnpm test        # 游戏规则测试
pnpm exec playwright install chromium
pnpm test:e2e    # 浏览器交互与响应式检查
```

## 操作与规则

- 鼠标移动瞄准并轻微转头，左键发射；按住连续射击，触屏可点按或长按。
- 键盘 1–7 依次选择铸币炉、分魂祭器、灵仆摇篮、祷告风琴、黑曜棱镜、黎明圣龛、丧钟；空格开枪；P / Esc 暂停。
- **初期**：铸币炉初始 1000 点升级，分魂祭器初始 10 点解锁双发；丧钟初始 100 秒，每枚 +1 秒，归零失败。
- **成长**：01:30、03:30、06:00、08:30 依次显现自动供币、结界修复、献祭增幅、终局封印的新祭器。
- **压力**：每两分钟的最后 25 秒出现侵袭；时间推进和升级都会提高黑暗侵蚀。祷告风琴强化修复、续命与庇护上限。
- **胜利**：黎明圣龛充满 18,000 点献祭，并生存到 12:00。逾期仍可继续，难度会继续提高。
- 手动铜币从枪口飞出，按射线命中的实际位置及到达时间分别结算。灵仆是独立的自动献祭，可自由指定已解锁目标。
- 每 5 秒保存本局进度，刷新后可主动选择继续。切换后台、窗口失焦和打开手册都会暂停。无离线收益。

完整游戏链路、成本、压力公式及平衡模拟记录见 [GAME_DESIGN.md](./GAME_DESIGN.md)。

## 实现

- `src/rules.ts`：独立规则、教程、章节、自动献祭、难度、胜负与存档校验。
- `src/world.ts`：Three.js 透视场景、枪与双手、祭器建模、灯光阴影、射线命中、铜币与粒子。
- `src/NightGame.tsx`：React 界面、系统向导、键盘控制、存档、手册和结算。
- `src/gothic.css`：哥特式界面的设计变量与响应式布局。旧版样式保留但不再载入。
- `src/audio.ts`：Web Audio 合成燧发枪、祭器共鸣、钟声与警告音。
- `src/rules.test.ts`、`tests/night.spec.ts`：规则、完整十二分钟策略模拟与真实浏览器验证。

场景模型与音效均由代码生成，无外部素材服务依赖。需要支持 WebGL 2 的浏览器；不支持时会显示恢复提示。场景是真实三维，但没有自由移动或完整物理引擎。
