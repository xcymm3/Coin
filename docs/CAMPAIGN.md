# 五页花园：数值策划与验收

## 当前规则

目标为新档、持续正常操作下约一小时通关。保留 21 种植物和原有随机抽种、单株浇水、助手运输流程，重做升级与推进经济。

- **60 项一次性改造**，每组三项；上一组三项买完后开放下一组。同组可自由选择购买顺序。商店提供待购买、下一组、已获得三个视图。
- **57 项改造 + 五页花园 + 累计收益 1.5 亿**开放终极种子。没有累计游戏时长硬锁；星之花成熟即通关，最后三项作为继续游戏的目标。
- 初始十盆；第四组把第一页扩到十五盆。第六、九、十二、十五组开放下一页，每页新增十五盆，最多 75 盆。
- 种子价格不变：0 / 50 / 300 / 1,800 / 10,800 / 64,800。累计收益解锁门槛为 0 / 2,000 / 60,000 / 3,000,000 / 150,000,000 / 150,000,000；终极还检查上述改造与花园条件。
- 前五档种子仍可抽出任一非终极植物；植物基础价值及概率见 [基础经济表](ECONOMY.md)。旧版 4 倍阶段时长不再作为当前验收标准。

## 模拟方法与结果

运行的是 `src/game.ts` 的真实 reducer，包含随机出苗、逐株冷却、装水、动物寻路、补给、背包和交付，不是只用平均收入除价格。

策略：每 1、2、3 或 5 秒一个操作机会；有钱时购买当前最便宜的改造，保留三包当前等级种子周转金；否则在最新花园收获、补种、浇水或补水。自动化优先策略在雇用松鼠后停止普通手工照料，但继续购买改造和种植终极。每局从十个空盆和零金币开始。操作模型把选择种子作为操作的一部分；实际切菜单、犹豫和离开游戏会增加现实用时。

### 独立随机样本验收

随机种子 1001–1015，每种操作频率十五局，共 45 局。校准基准为种子 42。

| 操作机会 | 通关范围（分钟） | 最长升级购买间隔（分钟） |
|---|---:|---:|
| 每 1 秒 | 51.41–55.43 | 2.12 |
| 每 3 秒 | 60.81–69.56 | 3.25 |
| 每 5 秒 | 65.18–79.51 | 4.83 |

所有样本均满足 50–80 分钟通关、最长升级购买间隔不超过五分钟。间隔包含开局到首购，以及最后一次购买到通关。这个指标比“当前没有任何可负担升级”的空窗更严格，因为还包含玩家有钱却正在做别的动作的时间。它不是对无限随机结果、任意购买顺序或长期挂机的数学保证。

### 种子 42 代表局

| 操作方式 | 通关（分钟） | 最长购买间隔 |
|---|---:|---:|
| 每秒一次 | 53.74 | 1.92 |
| 每两秒一次 | 61.34 | 2.30 |
| 每三秒一次 | 66.06 | 2.85 |
| 每五秒一次 | 74.93 | 4.58 |
| 每三秒、助手接管后停止普通手工照料 | 73.01 | 3.80 |

每两秒操作的代表局，新页分别在 16.77 / 26.40 / 36.70 / 46.17 分钟开放。

浏览器常规 250ms tick 的复核：种子 42，每 1 / 3 / 5 秒操作，分别 53.19 / 66.30 / 75.18 分钟通关，最大购买间隔均小于五分钟。主回归使用每秒 tick（内部至多 0.5 秒一步），两种粒度均达标。

### 自动化接管

每两秒代表局的五分钟窗口，甲虫实际交付金币与玩家实际收获金币之比：

- 第 15–20 分钟：约 2.07 倍。
- 第 25–30 分钟：约 3.92 倍。
- 第 35–40 分钟：约 5.37 倍。
- 第 55–60 分钟：约 12.27 倍。

这是交付来源统计，并非把土壤、浇水等共同作用后的全部增量利润因果归属于某个助手。自动化策略的通关复测也在目标范围内，说明后期确实可以交由助手维持经营。

## 调参过程

1. 简单指数价格配合大量 ×2 改造时，约 9.7 分钟就买空升级；主要问题是解锁高阶植物和新页的收入跃升没有计入价格。
2. 使用逐组二分校准，以约 3.25 分钟一组的累计购买节奏生成价格初稿。
3. 更换操作频率后，慢速玩家在第一只甲虫前出现六分钟空窗。把前三组基础价格从 110 / 278 / 1,378 调整到 80 / 210 / 650，并复测中后段价格。
4. 最终 45 局验收通过；终极不再依靠额外的钱包长时间堆积，改由建设进度和已有累计收益门槛开放。通关后保留第 20 组昂贵改造。
