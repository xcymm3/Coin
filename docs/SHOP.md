# 分园商店与动物团队（v4）

## 种子购买规则

所有种子只检查当前钱包余额，终极种子也只需 64,800 金币，不要求研究或花园数量。种子价格及植物收益不变。原先的一小时通关验收依赖已移除的限制，保留为下方历史记录。当前测试覆盖六档价格边界、消费后再次播种校验、松鼠自动选种和首园无研究通关。

## 商店范围

只有三个分类：升级、雇佣、装饰。已经买过的选项不再出现。动物数量和装备只显示各自可购买的下一档；未雇佣该动物时不显示装备。花园扩建在商店中单列；花园场景左右两侧箭头切换已开放花园，到达首尾时对应箭头禁用。

每园恰好三项专属研究，使用不同名称，效果全园共享。购买每园的丰收研究使收益 ×4，沃土研究使自然成长 ×2，灌注研究使手动浇水和水壶容量 ×2。全部十五项完成时，收益 ×1024、自然成长 ×32、手动浇水 +64 秒、玩家水壶 128 格，再叠加各园环境倍率。

## 独立动物团队

每园三种动物各最多五只，共十五只；全园最多七十五只。新花园从零只、木制装备开始，不免费复制旧园团队。

- 浇水蜗牛：取水 → 前往未成熟植物 → 浇水 → 水用完回池。
- 收获甲虫：前往成熟植物 → 采摘装筐 → 满载或没有成熟目标时返回 → 交付金币。
- 播种松鼠：补充种子 → 前往空盆 → 播种 → 袋空回箱补货。

松鼠选择当前钱包买得起的最高级非终极种子，不依赖累计收益。

同种动物预约不同目标，甲虫采摘时记录图鉴与肥料掉落、交付时才结算金币。页面切换和离线期间，各园仍独立工作。收获和播种开关也各园独立。选择、种植终极种子和切换花园均不会暂停助手。松鼠始终只播种非终极种子，甲虫保留终极植物；若要为手动播种留出空盆，可主动关闭本园自动播种。

以该园首次蜗牛价格为 B，蜗牛／甲虫／松鼠各自基础价为 B、1.5B、2B。每种动物第 n 只价格为基础价 × 4^(n−1)，n=1…5。铜、铁、金、钻石装备价格为该种基础价 × 3 × 4^(档位−1)，档位=1…4。装备影响本园同种所有动物，包括以后雇佣的动物。

## 装饰

六项装饰分别按园购买，价格为首园价乘以 1、8、64、512、4096。只影响外观，不增加研究数量或任何生产能力。已购买装饰在设置中控制显隐；详细基础价见 [收集规则](COLLECTIBLES.md)。

## 旧解锁规则的历史验收（已不适用于当前通关时长）

`pnpm test` 验证新系统及历史存档。`tests/legacy-game.test.mjs` 明确用于 v1–v3 的历史回归；当前商店、分园状态、动物预订与配送、扩建、迁移、存档由 `tests/game.test.mjs` 覆盖。

45 组未用于校准的品种随机种子（1001–1015，每 1、3、5 秒一次操作）结果：通关 **59.575–74.975 分钟**，最长购买间隔 **3.417 分钟**，均满足 50–80 分钟和五分钟内有购买的目标。另测三个自动化优先样本和三种 250ms 浏览器节拍，均通过同样断言；后期自动交付金额超过手动收获两倍。

策略：按当前花园可购生产选项价格由低到高购买，保留三包种子资金；有空闲操作时收获、播种、浇水，主要照料最高园；旧园交给动物。不购买装饰、不消耗肥料，未强制买满动物与装备。间隔从实际购买到下一次购买计算，包含雇佣、装备和扩建；装饰不用于填补间隔。不同购买策略、频繁装饰消费或完全不操作会改变时长。

浏览器开发预览验证：购买研究后从列表消失、满编雇佣空态、不同花园的数量与材料、独立装饰定价、木／铁／钻石装备和走路动作、375px 手机商店布局。浏览器检查为功能与画面测试，通关时间来自实际 reducer 模拟，不是实时时长试玩。

## 旧存档迁移

保留已有钱、植物、图鉴、肥料、外观收集、天气、通关记录和配送中货物；已开放花园获得原先在该页工作的动物，旧装备等级映射到新材料。旧全园装饰分配到已开放各园，以后开辟的花园没有装饰。已购生产能力映射为新研究，多出的全局能力记为历史加成保留。新版本之后的购买遵循分园规则。旧版存档解析保留在 `legacyGame.ts` / `legacyUpgrades.ts`，不作为新游戏引擎使用。

## 花园内的工具与跨园搬运

工具嵌入花园顶部，与场景共用背景；水壶、肥料、小推车、铲子靠左排列，工具之间保留固定间距，每件工具都有木制像素边框。选中小推车，再选植物，可通过场景左右箭头切换花园，点击空盆搬运或点击其他植物交换位置。小推车显示待搬植物缩略图；再点小推车或切换工具取消。确认目标前植物仍在原盆，助手可能将其收获，此时需重新选择。搬运保留品种、变体、萌发及成长进度和浇水冷却，不结算收获；两边花盆已有的助手预约会取消并重新寻找工作。

## 五园场景

背景分为远景、建筑围护、种植地面与前景边缘，均使用像素图形，不改变游戏数值。苔庭温室具有玻璃棚架、窗外树影、后窗盆栽、灯具和石板地面；萤火溪谷具有树林、水道与苔岸；琥珀沙庭具有砂岩远山、石柱、仙人掌与砂地；极光雪苑具有极光、雪山、冰玻璃与暖炉；星海天台具有月亮、星带、城市剪影与石质露台。

水池放大为可点击的打水点。水壶按钮只选择工具；水量不足时点击花园左下角水池，播放打水动画并按原有装填时间补满。装填中及满水时不能重复打水，蜗牛仍使用同一水池补给。
