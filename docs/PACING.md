## 规则与曲线

- 每园从 4 盆起步，商店每次购买 +1，上限 15。新增盆价格为 round(8 × 本园系数 × 1.55^(已有盆数−4))，系数依次为 1 / 50 / 3000 / 300000 / 30000000。满 15 盆且完成本园三项研究后，才可开下一园。
- 开园费用依次为 0 / 16,000 / 20,000,000 / 1,400,000,000 / 90,000,000,000。研究基价为 270 / 500,000 / 9,600,000 / 1,500,000,000 / 150,000,000,000；丰收、土壤、灌注分别乘 1 / 1.4 / 1.9。
- 首园花盆价格从 8、12、19、30 开始；免费种子 20 秒基础成长，手动浇水加速。先照料、扩盆，再逐步雇佣助手；后期依靠更多助手、装备与旧园收入积累。样本首次购买范围 16–22 秒，前五分钟无可执行动作比例最高 0.0%。
- 八档种子价格为 0 / 50 / 500 / 10,000 / 500,000 / 50,000,000 / 10,000,000,000 / 15,000,000,000,000。七档常规基础成长为 20 / 40 / 70 / 140 / 260 / 500 / 850 秒。每档四品种，品种概率为 20% / 50% / 25% / 5%。种子多数产出本档；跨档概率由 catalog.ts 的 SEED_ODDS 定义，稀有高阶抽取仍会造成时间波动。
- 常规各档最稀有品种各有一个不同的专属变种，条件概率 10%，收获 ×2（手动和自动均生效）。其他品种及终极无变种。只有手动收获有 5% 概率获得肥料，施肥使非终极植物立即成熟。
- 终极基础成长 27,000 秒。五园研究齐备时，第五园自然成长速度 ×80，自然成熟 337.5 秒；手动与蜗牛照料约 5 分钟，每 5 秒吸收一次浇水，不可施肥。
- 水壶工具栏、倾倒和补水使用同一个 ToolArt 组件。蜗牛恢复历史提交 702bb93 的圆润造型，动物不绘制携带装备；保留作业时的水滴、播种和采摘反馈。
- 旧档保留已拥有的盆数、金币、团队与收获记录，生长按旧植物时长比例换算；旧变体记录保存在 legacyVariants。新节奏以新档为准。

## 可复现方法与限制

运行 npm run check:pacing。随机种子 1001–1015，品种、变种、天气均固定；使用真实 reducer，包含助手寻路、补给、交付、离屏花园、施肥和单株浇水。原始结果写入 .artifacts/pacing-results.json。

策略只照料最新花园，按不含临时天气倍率的长期预计净收入挑选可负担种子，保留最多三包周转金，优先买可负担的便宜升级。每园每类助手最多购买园序号数量（首园 1 只，第五园 5 只），旧园继续按原指定种子经营。播种选种视为一次决策的组合操作，菜单切换和玩家思考时间不计；不是完整人类操作实测。

自动验收门槛：阶段平均与目标偏差 ≤15%，每局终极 4.5–5.6 分钟，首次购买 ≤36 秒，前五分钟空闲机会 ≤10%。这衡量平均节奏，不保证每个随机局都在目标附近；首园和第四园仍有明显随机差异。不能把频繁点击直接视为内容丰富度，实际体验仍需试玩评估。

天气效果加入前的历史操作频率敏感性（种子 42，以下不是当前复测结果）：每 1 / 3 / 5 秒决策，总长分别为 62.20 / 67.44 / 77.09 分钟；慢速操作主要拖长首园。前期手动投入会影响通关时间，挂机或随意购买不承诺同样时长。

## 天气加成

每 5–10 分钟触发一次，三类等概率，各持续 15 秒。细雨全园自然成长 ×2，萤火虫之夜按采摘时刻使收益 ×7（可叠加变种），彩虹使玩家水壶无限供水且不扣原有存水。效果结束即恢复；甲虫已采摘货物保留采摘时价值。复测保持原有价格和验收门槛，详细规则见 [COLLECTIBLES.md](COLLECTIBLES.md)。
