## 规则与曲线

- 每园从 4 盆起步，商店每次购买 +1，上限 15。新增盆价格为 round(8 × 本园系数 × 1.55^(已有盆数−4))，系数依次为 1 / 50 / 3000 / 300000 / 30000000。满 15 盆且完成本园六级研究后，才可开下一园。
- 开园费用依次为 0 / 330,000 / 10,000,000 / 1,000,000,000 / 100,000,000,000。研究基价为 270 / 500,000 / 9,600,000 / 1,500,000,000 / 150,000,000,000；丰收分四级，每级倍率 ×√2（约 +41%，四级合计 ×4），首园分别花费 40 / 65 / 85 / 110，后续园分别乘基价 0.15 / 0.25 / 0.35 / 0.5；土壤、灌注分别乘 1.4 / 1.9。四级丰收依次需本园收获 0 / 12 / 30 / 60 株，商店只显示下一丰收等级。
- 首园花盆价格从 8、12、19、30 开始；免费种子 20 秒基础成长，手动浇水加速。先照料、扩盆，再逐步雇佣助手；后期依靠更多助手、装备与旧园收入积累。样本首次购买范围 16–22 秒，前五分钟无可执行动作比例最高 0.0%。
- 八档种子价格为 0 / 50 / 500 / 10,000 / 500,000 / 50,000,000 / 10,000,000,000 / 23,000,000,000,000。七档常规基础成长为 20 / 40 / 70 / 140 / 260 / 500 / 850 秒。每档四品种，品种概率为 20% / 50% / 25% / 5%。种子多数产出本档；跨档概率由 catalog.ts 的 SEED_ODDS 定义，稀有高阶抽取仍会造成时间波动。
- 付费常规种子额外检查本园常态产值：本档占比最高的品种（50% 概率）的正常收益须达到种价 110%，并额外校验包含跨阶抽取的常态期望收获严格大于种价，不依赖天气或变种。超凡、神话、远古、星界不再只凭钱包解锁。播种记录实际付款，成熟收获按品种正常产值结算，之后叠加变种和天气，不再补足种子成本。随机降阶与跨园搬运均保留成本；手动、自动一致。挖除不退费，终极用于通关不结算收获。
- 每次本园招募或装备升级后，下一次团队购买至少间隔 45 秒，已有动物照常工作。第 1–5 只招募需本园收获 0 / 40 / 90 / 160 / 250 株，铜至钻石装备需 30 / 70 / 140 / 240 株；甲虫另加 12 株，松鼠另加 24 株。手动、自动采摘都累计，换园不共用经验，进度及倒计时随存档保存。
- 常规各档最稀有品种各有一个不同的专属变种，条件概率 10%，收获 ×2（手动和自动均生效）。其他品种及终极无变种。只有手动收获有 5% 概率获得肥料，施肥使非终极植物立即成熟。
- 终极基础成长 27,000 秒。五园研究齐备时，第五园自然成长速度 ×80，自然成熟 337.5 秒；手动与蜗牛照料约 5 分钟，每 5 秒吸收一次浇水，不可施肥。
- 水壶工具栏、倾倒和补水使用同一个 ToolArt 组件。蜗牛使用 40×32 整数网格的可爱像素造型，大眼睛与螺旋壳保留，步进动画不再拉伸身体，动物不绘制携带装备；保留作业时的水滴、播种和采摘反馈。
- 原 balanceVersion=1 存档的已购 ×4 丰收研究映射为四级全部完成，不重复付费，不削减已有倍率；已拥有团队保留。旧档未记录各园收获次数，新门槛从升级后的本园收获开始累计；旧植物没有播种成本记录，继续原产值结算。更早的旧档保留已拥有的盆数、金币、团队与收获记录，生长按旧植物时长比例换算；旧变体记录保存在 legacyVariants。新节奏以新档为准。

## 可复现方法与限制

运行 npm run check:pacing。随机种子 1001–1015，品种、变种、天气均固定；使用真实 reducer，包含助手寻路、补给、交付、离屏花园、施肥和单株浇水。原始结果写入 .artifacts/pacing-results.json。

策略只照料最新花园，按不含临时天气倍率的长期预计净收入挑选可负担种子，保留最多三包周转金，优先买可负担的便宜升级。每园每类助手最多购买园序号数量（首园 1 只，第五园 5 只），旧园继续按原指定种子经营。播种选种视为一次决策的组合操作，菜单切换和玩家思考时间不计；不是完整人类操作实测。

自动验收同时断言每园连续团队购买至少间隔 45 秒，且实际扣款与记录一致。自动验收门槛：阶段平均与目标偏差 ≤15%，每局终极 4.5–5.6 分钟，首次购买 ≤36 秒，前五分钟空闲机会 ≤10%。这衡量平均节奏，不保证每个随机局都在目标附近；首园和第四园仍有明显随机差异。不能把频繁点击直接视为内容丰富度，实际体验仍需试玩评估。

移除保底前的策略敏感性历史复测（随机种子 42）：每 3 / 5 秒决策，总长分别为 71.73 / 81.14 分钟。每 2 秒决策且总选可负担的最高档种子，总长 65.13 分钟。前期手动投入仍明显影响时长；挂机、慢速操作或随意购买不承诺同样时长。回归测试覆盖各档基础倍率下同阶有亏有赚、允许播种时同阶与跨阶总体期望为正，以及手动和自动收获的亏损结算。研究和花园加成可使原本亏损的品种转为盈利。

## 天气加成

每 5–10 分钟触发一次，三类等概率，各持续 15 秒。细雨全园自然成长 ×2，萤火虫之夜按采摘时刻使收益 ×7（可叠加变种），彩虹使玩家水壶无限供水且不扣原有存水。效果结束即恢复；甲虫已采摘货物保留采摘时价值。本轮保留天气规则和时长验收门槛，重新校准开园及终极种子价格，详细规则见 [COLLECTIBLES.md](COLLECTIBLES.md)。


## 全园研究与场景扩盆交互

丰收、沃土、灌注采用统一名称，所有花园显示同一份下一待购研究列表。研究第 1–5 级分别由第一至第五园解锁；丰收每级仍分四次渐进强化（如“丰收研究 2级 · 1/4”），价格与全园效果不变。完成当前园阶段后，即可看到灰色的下一等级及开园条件。已有存档按原研究 ID 识别，无需重新购买。

花盆扩建从商店移至场景：只在下一个可购买位置显示标价的＋，点击扣除标示金币并增加一盆，满 15 盆后入口消失，金币不足时禁用。后续空位是不可点击的标记，避免点击远处却买到别处的盆。新花园开辟仍在商店。

游戏文字和符号禁止拖选、长按选择与 Ctrl/Cmd+A 全选；文本输入区域保留正常编辑能力。测试脚本 scripts/unified-shop-check.mjs 覆盖 PC、390px、320px 下直接扩盆、封顶、灰色研究解锁、跨园同步与全选阻止。
