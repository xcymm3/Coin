# 六品阶花园经济设计

## 计算口径

初始 10 个花盆，无升级、不浇水、不挖除，植物成熟后立即收获补种。按累计收获金币（毛收入，不是钱包余额或净利润）解锁下一档；达到门槛后切换种子，旧植物继续长完。解锁不额外扣费，购买种子才扣费。每个阶段的目标是 5、20、80、320、1280 分钟，均为阶段耗时，不是从开局计时。到终极累计约 28 小时 25 分钟，再培养 8 分钟星之花通关。

随机结果会使单局偏离平均值；手动操作延迟、停留菜单、升级和浇水都会改变实际耗时。这是事件模拟，不是 28 小时浏览器实玩。

## 存档与现有系统

保留原十种植物的 ID；旧存档按成熟比例迁移成长时间，金币、发现记录、助手和通关记录保留。不足十盆补到十盆，已有十至十五盆保持原数量，扩建等级按新起点换算。未通关存档按新经济门槛解锁，已通关存档保留全部种子可用。所有新植物有独立幼芽和像素成株，沿用五秒有效成长萌发、单株浇水、珍贵及以上揭晓闪光及音效。
